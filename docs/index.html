ABAP VERTEX Tools

ABAP Version, Code and Data Explorer, inside ABAP Development Tools.

This address is an Eclipse update site, not a page to read. There is nothing here for a browser, which is why you landed on it. Copy it and hand it to Eclipse:

https://ysichov.github.io/VERTEX/
  1. In Eclipse, Help → Install New Software…
  2. Add…, paste the address above into Location, give it any name.
  3. Tick the category ABAP VERTEX Tools, then Next and Finish.
  4. Restart Eclipse when it asks.

Then Window → Show View → Other… → VERTEX, or right-click an object in the Project Explorer and pick VERTEX.

ADT has to be installed first. The feature declares the SAP bundles as prerequisites rather than shipping them, so p2 refuses the install on an Eclipse without ADT instead of leaving a plugin that cannot resolve.

The other half is ABAP

VERTEX is a front end and a set of ADT resources. The plugin alone reaches a path nothing answers, and every window will say so. Pull these into the system with abapGit and activate them:

  1. Simple Data Explorer — the ADT resources every VERTEX window reads, and the tables, joins and pivot
  2. ACE — the metrics and the branch schemes
  3. AVE — the versions, diffs and code review

One BAdI registration follows, under /sap/bc/adt/zsde/*. The steps are in the README, and the window tells you the same thing if you open it before the ABAP is there.
