Visual Debug

Run in SAP starts the program in WebGUI and the breakpoints catch it there. Run with ABAP Transpiler runs it on this machine: a program opens in its own window - selection screen, Execute (F8), the list, Back (F3) - and Run here brings that window back; a method or a function module asks its parameters first.

An SAP object runs its last build, as SAP runs a load. Recompile reads it and what it uses from SAP again; its tooltip says when the build was read.

Single Step, Execute, Return and Continue (F5-F8, here or in the editor) step from a stop. A transpiler run records every step: the slider replays it, and Variables shows the routine's values, SY and the SELECTs of the statement before.

Output is what the program wrote; a call's results follow it, structures as trees and tables as columns. A failed run names the ABAP line it stopped on.

Exit program ends a stopped program; for an SAP run, Detach lets it go on and stops listening. The breakpoints stay for the next run. Clear starts this panel again.

Click a linked label or a breakpoint's place to open its source; Alt+Left returns. The bug button copies the full diagnostic log.

The zoom slider is 10-100%. The lens works below 70%, magnifying up to that effective scale. Changing the theme preserves zoom and position.

Visual Debug Click beside a line number to set a breakpoint; right-click for a condition.
